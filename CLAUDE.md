# Claude Code entry point

Read and follow @AGENTS.md, then @README.md, @HANDOFF.md and @CALIBRATION.md.

The authoritative processing preset is settings.json. Use voiceover.py to produce MP3, WAV and JSON in one command. Check dependencies with `python voiceover.py --check`. Do not replace the processor with a newly invented algorithm for each recording.

No OpenAI integration or original chat import is needed. The user supplies a local audio path and any recording-specific exceptions. Ask for listening feedback rather than claiming the output is acoustically flawless.
